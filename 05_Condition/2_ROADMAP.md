# 📘 Day 4: JavaScript Conditions

Welcome to **Day 4** of the **JavaScript Foundation Mastery** roadmap.

Today, you will learn one of the most important concepts in programming: **Conditions**.

Conditions allow JavaScript to make decisions based on different situations. Every software application, from a login system to an enterprise CRM or LMS, uses conditions to determine what action should be performed.

---

# 🎯 Goal

Understand how JavaScript makes decisions using:

- `if`
- `else`
- `switch`

By the end of today, you will be able to build decision-making logic and solve real business problems using conditions.
