# 📖 Introduction

Conditions are one of the core building blocks of programming.

They allow software to make decisions based on different situations.

Without conditions, every JavaScript program would execute every statement one after another without any decision-making.

Almost every modern application uses conditions, including:

- CRM Systems
- LMS Platforms
- E-Commerce Websites
- Banking Applications
- Authentication Systems
- Inventory Management Software

Today you will understand how JavaScript decides **what should happen and when it should happen**.
