# 🟦 Day 16 — Object Properties

### 📅 22 September 2026

## 🧠 1. What are Object Properties?

**Object Properties** are the **key-value pairs** used to store information inside an object.

```js
const student = {
    name: "Krishna",
    age: 20,
    course: "English"
};
```

### 📌 Structure

```text
        STUDENT OBJECT
              │
      ┌───────┼────────┐
      ↓       ↓        ↓
    name     age     course
      │       │        │
  "Krishna"   20    "English"
```

---

## 📖 2. Property Structure

```js
property: value
```

Example:

```js
name: "Krishna"
```

| Part        | Meaning        |
| ----------- | -------------- |
| `name`      | Property / Key |
| `"Krishna"` | Value          |

### 🧠 Memory Rule

**Property = Name of the information**
**Value = Actual information**

---

# 💻 3. Creating Object Properties

```js
const student = {
    name: "Krishna",
    age: 20,
    course: "English"
};

console.log(student);
```

### 📊 Object Map

```text
student
   │
   ├── name   → "Krishna"
   │
   ├── age    → 20
   │
   └── course → "English"
```

---

# 🔍 4. Accessing Object Properties

Use **dot notation**:

```js
student.name
student.age
student.course
```

Example:

```js
console.log(student.name);
```

Output:

```text
Krishna
```

### 🔄 Flow

```text
student
   ↓
.name
   ↓
"Krishna"
```

# ⚠ Common Mistakes

### ❌ Missing comma

```js
const student = {
    name: "Krishna"
    age: 20
};
```

### ✅ Correct

```js
const student = {
    name: "Krishna",
    age: 20
};
```

### ❌ Wrong property access

```js
student.Name
```

if the property was defined as:

```js
name: "Krishna"
```

JavaScript property names are **case-sensitive**.
