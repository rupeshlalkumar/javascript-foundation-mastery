# 🟦 Day 18 — Objects + Arrays

### 📅 24 September 2026

## 🧠 1. Objects + Arrays

**Objects** store information about **one entity**.

**Arrays** store **multiple values**.

Together:

```text
Array
  │
  ├── Object → Student 1
  │
  ├── Object → Student 2
  │
  └── Object → Student 3
```

# 🧩 3. Array → Object → Property

```text
students
   │
   ↓
[0]
   │
   ↓
Student Object
   │
   ├── name
   ├── age
   └── course
```

### 💻 Access a Student

```js
console.log(students[0]);
```

### Access a Property

```js
console.log(students[0].name);
```

```text
students
   ↓
[0]
   ↓
.name
   ↓
"Krishna"
```

# 💼 5. Project

## **Multiple Students System**

### 🎯 Goal

Store **multiple students** using:

```text
Array
  +
Objects
  +
Student Properties
```

### Basic Pattern

```js
const students = [];

students.push({
    name: "Krishna",
    age: 20,
    course: "English"
});
```

Add another:

```js
students.push({
    name: "Anurag",
    age: 21,
    course: "Computer Science"
});
```

# 🧠 6. Core Concept

```text
ONE STUDENT
     ↓
  Object
     ↓
Multiple Students
     ↓
   Array
```

### 📌 Memory Rule

**Object = One Student**

**Array = Multiple Students**

**Array of Objects = Multiple Students System**

# ⚠ Common Mistake

```js

```

### ✅ Array of objects

```js

    {},
    {},
    {}
```
