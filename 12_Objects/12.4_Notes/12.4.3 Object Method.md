# 🟦 Day 17 — Object Methods

### 📅 23 September 2026

## 🧠 1. What is an Object Method?

An **Object Method** is a **function stored inside an object**.

```text
Object
   │
   ├── Property → Data
   │
   └── Method   → Action / Function
```

### 📊 Simple Difference

```text
PROPERTY                    METHOD
   ↓                           ↓
Stores data                Performs an action
   ↓                           ↓
name: "Krishna"            showInfo()
```

---

# 💻 2. Creating an Object Method

```js id="k6c4vp"
const student = {
    name: "Krishna",
    age: 20,
    course: "English",

    showInfo: function() {
        console.log("Student Information");
    }
};
```

### 📊 Object Structure

```text
┌─────────────────────────────┐
│          student            │
├─────────────────────────────┤
│ name   → "Krishna"          │
│ age    → 20                 │
│ course → "English"          │
│                             │
│ showInfo() → function       │
└─────────────────────────────┘
```

---

# 🔄 3. Calling an Object Method

The method is called using:

```js id="x2a9qk"
student.showInfo();
```

### 🔄 Flow

```text
student
   ↓
.showInfo()
   ↓
method executes
   ↓
"Student Information"
```

# 🧠 5. Method = Function Inside Object

```text
FUNCTION
   ↓
Performs an action

OBJECT METHOD
   ↓
Function inside an object
   ↓
Called with:
student.showInfo();
```

### 📌 Memory Rule

**Object → Method → Action → Call**

```text
student
   ↓
showInfo
   ↓
function executes
   ↓
student.showInfo();
```

---

# ⚠ Common Mistake

### ❌ Defining only

```js
showInfo: function() {
    console.log("Student Information");
}
```

This **defines** the method but does not execute it.

### ✅ Call the method

```js
student.showInfo();
```
