# 🟦 Day 19 — Nested Objects

### 📅 25 September 2026

## 🧠 1. What is a Nested Object?

A **Nested Object** is an **object inside another object**.

```text
Object
   │
   └── Object
        │
        ├── Property
        └── Property
```

### 💡 Simple Idea

```js
const customer = {
    name: "Rupesh",
    address: {
        city: "Katihar",
        state: "Bihar"
    }
};
```

Here:

```text
customer
   │
   ├── name
   │
   └── address
          │
          ├── city
          └── state
```

---

# 📊 2. Nested Object Structure

```text
┌─────────────────────────────┐
│         CUSTOMER            │
├─────────────────────────────┤
│ name → "Rupesh"             │
│                             │
│ address → OBJECT            │
│     │                       │
│     ├── city  → "Katihar"  │
│     └── state → "Bihar"    │
└─────────────────────────────┘
```

### 🧠 Key Concept

```text
Customer Object
      ↓
Address Property
      ↓
Address Object
      ↓
City + State
```

---

# 💻 3. Creating a Nested Object

```js
const customer = {
    name: "Rupesh",

    address: {
        city: "Katihar",
        state: "Bihar"
    }
};
```

The `address` property contains **another object**.

---

# 🔍 4. Accessing Nested Properties

To access a property inside the nested object:

```js
customer.address.city
```

Output:

```text
Katihar
```

### 🔄 Access Flow

```text
customer
   ↓
address
   ↓
city
   ↓
"Katihar"
```

Another example:

```js
console.log(customer.address.state);
```

Output:

```text
Bihar
```

# 🧠 7. Nested Object Access

### Normal property

```js
customer.name
```

### Nested property

```js
customer.address.city
```

### Deeper structure

```text
object
  ↓
property
  ↓
nested object
  ↓
property
```

---

# ⚠ Common Mistake

### ❌ Incorrect

```js
customer.city
```

`city` is **inside `address`**, not directly inside `customer`.

### ✅ Correct

```js
customer.address.city
```
