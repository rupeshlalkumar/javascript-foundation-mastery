### 📅 26 September 2026

## 🧠 1. What is JSON?

**JSON** stands for **JavaScript Object Notation**.

It is a common **data format** used to store and exchange structured data.

```text id="9p4k6x"
              JSON
                │
       ┌────────┴────────┐
       ↓                 ↓
   Store Data       Exchange Data
       │                 │
       └────────┬────────┘
                ↓
        Structured Data
```

---

# 📊 2. JSON Structure

JSON looks similar to a JavaScript object:

```json id="m8x2qv"
{
    "name": "Krishna",
    "age": 20,
    "course": "English"
}
```

### Visual Structure

```text id="q3w7na"
┌──────────────────────────┐
│          JSON            │
├──────────────────────────┤
│ "name"   → "Krishna"    │
│ "age"    → 20           │
│ "course" → "English"    │
└──────────────────────────┘
```

---

# 🔑 3. JSON Key + Value

JSON uses:

```text id="k5d9rs"
"key" : value
```

Example:

```json id="c1v8ty"
"name": "Krishna"
```

```text
"name"      → Key
"Krishna"   → Value
```

### ⚠ Important

JSON property names are written using **double quotes**:

```json id="n2x7bm"
{
    "name": "Krishna"
}
```

---

# 🔄 4. JavaScript Object vs JSON

### JavaScript Object

```js id="z6p3qw"
const student = {
    name: "Krishna",
    age: 20
};
```

### JSON

```json id="r4v8kc"
{
    "name": "Krishna",
    "age": 20
}
```

### 📊 Visual

```text id="u9s2jd"
JavaScript Object
       │
       │  data structure
       ↓
   { name: "Krishna" }

          ↕

       JSON
       │
       │  data format
       ↓
{ "name": "Krishna" }
```

# ⚠ Common Mistakes

### ❌ Single quotes

```json id="h4q9zs"
{
    'name': 'Krishna'
}
```

### ✅ Double quotes

```json id="d7w2kc"
{
    "name": "Krishna"
}
```

### ❌ Trailing comma

```json id="s1n6vb"
{
    "name": "Krishna",
    "age": 20,
}
```

### ✅ Correct

```json id="a9f3xe"
{
    "name": "Krishna",
    "age": 20
}
```
