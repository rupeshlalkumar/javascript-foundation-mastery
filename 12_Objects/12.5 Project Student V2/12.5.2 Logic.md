# 🧠 Student Manager v2 — Logic Only

Think of the whole application as:

```text
STUDENT MANAGER
      ↓
Student Data
      ↓
┌───────────────┐
│               │
▼               ▼
ADD           VIEW
│
▼
Student Array
│
▼
DELETE
```

## 1. 🟢 Add Student

Ask yourself:

> **Where will I store students?**

Logic:

```text
Start
  ↓
Create empty student array
  ↓
User enters student information
  ↓
Create student object
  ↓
Add object to array
  ↓
Student is stored
```

Think about:

* What information does one student have?
* How will you create the student object?
* Which array method adds something to an array?

---

## 2. 🔵 View Student

Ask yourself:

> **Where are my students?**

Logic:

```text
Student Array
      ↓
Get students
      ↓
Go through each student
      ↓
Display student information
```

Now connect this with what you learned:

```text
Array
  ↓
Iteration
  ↓
Each Student
  ↓
Display
```

Think:

> "If I have 5 students, how will I access each student?"

---

## 3. 🔴 Delete Student

This is the most important debugging-thinking part.

Don't immediately think about code.

Ask:

> **How will I identify which student the user wants to delete?**

For example:

```text
Students
   ↓
Student ID
   ↓
Find matching student
   ↓
Remove that student
   ↓
Updated Student Array
```

Think about these questions:

1. How does each student get a unique ID?
2. How do I find the student with that ID?
3. Once I find it, how do I remove it?
4. What happens to the array after deletion?

# 🧠 Your Debugging Framework

For every feature, ask these **5 questions**:

```text
1. INPUT
   ↓
What does the user give me?

2. DATA
   ↓
Where do I store it?

3. LOGIC
   ↓
What operation do I need?

4. OUTPUT
   ↓
What should the user see?

5. DEBUG
   ↓
What value should I check in console?
```
