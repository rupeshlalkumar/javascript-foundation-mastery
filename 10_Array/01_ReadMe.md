## 🎯 Goal

Learn the fundamentals of **JavaScript Arrays** and understand how to store and work with multiple values inside a single variable.

---

## 📖 Learn

### Topic: Arrays

Today you will learn:

* What Arrays are
* Why Arrays are used
* How to create an Array
* How to store multiple values
* How to access Array values
* How Array indexes work
* How to work with an empty Array
* How Arrays can be used with loops
* How Arrays are used in real-world applications

### Basic Example

```js
const products = [
    "Laptop",
    "Mouse",
    "Keyboard"
];
```

# 🧠 Developer Thinking

Arrays are important because applications rarely work with only one piece of data.

Instead of:

```js
const product = "Laptop";
```

you will start thinking about:

```js
const products = [
    "Laptop",
    "Mouse",
    "Keyboard"
];
```

This is the beginning of working with **collections of data**.
