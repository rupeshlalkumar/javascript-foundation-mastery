## 📖 1. LEARN

### Topic: Arrays

**Goal:** Understand how JavaScript stores and manages multiple values inside a single variable.

```text id="learn-array"
Single Value

const product = "Laptop";


Multiple Values

const products = [
    "Laptop",
    "Mouse",
    "Keyboard"
];
```

### Learning Path

```text id="array-learning-path"
Array
  ↓
What is an Array?
  ↓
Why do we need Arrays?
  ↓
Create an Array
  ↓
Store Multiple Values
  ↓
Array Index
  ↓
Access Array Items
  ↓
Change Array Items
  ↓
Add Items
  ↓
Remove Items
  ↓
Array Length
  ↓
Loop Through Array
  ↓
Business Applications
```

### 🧠 Core Mental Model

```text id="array-index"
const products = ["Laptop", "Mouse", "Keyboard"];

                ARRAY
                  │
        ┌─────────┼─────────┐
        ↓         ↓         ↓
     Index 0   Index 1   Index 2
        │         │         │
        ↓         ↓         ↓
    "Laptop"   "Mouse"  "Keyboard"
```

> 🔴 Remember: JavaScript arrays use **zero-based indexing**.
