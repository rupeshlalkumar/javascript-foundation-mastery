# 📘 Day 5: JavaScript Loops

Welcome to **Day 5** of the **JavaScript Foundation Mastery** roadmap.

Today, you'll learn one of the most important programming concepts: **Loops**.

Loops help us execute a block of code repeatedly without writing the same code multiple times. They are a fundamental building block in every programming language and are widely used in real-world software development.

# 🌍 Why Learn Loops?

Without loops:

```javascript
console.log(1);
console.log(2);
console.log(3);
console.log(4);
console.log(5);
```

With loops:

```javascript
for (let i = 1; i <= 5; i++) {
    console.log(i);
}
```

Instead of writing repetitive code, a loop performs the same task automatically.
