# 🗺️ Day 5 Roadmap: JavaScript Loops

Welcome to **Day 5** of the **JavaScript Foundation Mastery** roadmap.

Today, you will learn one of the most powerful concepts in programming: **Loops**.

Loops allow JavaScript to execute the same block of code multiple times without writing repetitive code. Every modern software application, from CRM systems to banking software, uses loops to process data efficiently.

---

# 🎯 Goal

Understand how JavaScript automates repetitive tasks using:

* `for` Loop
* `while` Loop

By the end of today, you will be able to generate sequences, process collections of data, and build logic for real-world business applications.

# 💻 Practice

Create examples of:

## `for` Loop

```javascript
for (let i = 1; i <= 5; i++) {
    console.log(i);
}
```

Practice:

* Print Numbers (1–10)
* Print Even Numbers
* Print Odd Numbers
* Multiplication Table
* Countdown
* Reverse Counting

---

## `while` Loop

```javascript
let i = 1;

while (i <= 5) {
    console.log(i);
    i++;
}
```

Practice:

* Count 1–10
* Countdown
* Sum of Numbers
* Password Attempts
* Balance Checking
