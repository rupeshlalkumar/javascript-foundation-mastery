# 🟦 DAY 24 — `find()`

### Business Logic Foundation | Searching Data

---

## 🧠 1. Core Concept

> **`find()` searches an array using a condition and returns the first item that matches.**

```text
ARRAY
  ↓
find()
  ↓
Search Condition
  ↓
First Matching Item
```

### 📖 Definition

**`find()`** is an array method used when you want to **search for a specific item** inside an array.

---

# 🔵 2. `filter()` vs `find()`

You learned `filter()` yesterday.

```text
filter() → Find ALL matching items
find()   → Find FIRST matching item
```

### Example

```text
Customers
    ↓
┌────────┬────────┬────────┬────────┐
│ Rahul  │ Ram    │ Shyam  │ Krishna│
└────────┴────────┴────────┴────────┘
              ↓
            find()
              ↓
       First Match Only
```

### 🧠 Memory Formula

```text
filter()
  = Select multiple
  = New Array
```

```text
find()
  = Search
  = First Match
  = Single Item
```

---

# 💻 3. Basic Syntax

```js
const result = array.find(item => {
    return condition;
});
```

The condition determines whether an item matches.

```text
true  → STOP + RETURN THIS ITEM
false → Continue Searching
```

---

# 📊 4. How `find()` Works

Suppose:

```js
const numbers = [10, 20, 30, 40];
```

You want to find `30`.

```text
10 → Match? ❌ → Continue
20 → Match? ❌ → Continue
30 → Match? ✅ → RETURN 30
40 → Not checked
```

### 🔑 Important

`find()` **stops when it finds the first match**.

```text
ARRAY
  ↓
Check Item 1 → ❌
  ↓
Check Item 2 → ❌
  ↓
Check Item 3 → ✅
  ↓
RETURN Item 3
  ↓
STOP
```

# 🎯 5. Practice — Find Customer By ID

Suppose you have:

```js
const customers = [
    {
        id: 101,
        name: "Rahul"
    },
    {
        id: 102,
        name: "Ram"
    },
    {
        id: 103,
        name: "Shyam"
    }
];
```

### 🎯 Goal

Find the customer whose ID is:

```text
103
```

### 🧠 Think Before Coding

Your logic should be:

```text
Customer Array
      ↓
    find()
      ↓
Check Customer ID
      ↓
Is ID = 103?
    ↙       ↘
  YES        NO
   ↓          ↓
RETURN     Continue
Customer   Searching
```

---

# 💼 6. CRM Example

Imagine a CRM has many customers:

```text
Customer Database
        ↓
      find()
        ↓
    Search by ID
        ↓
   Customer Found
```

For example:

```js
const customer = customers.find(customer => {
    return customer.id === 103;
});
```

Result:

```js
{
    id: 103,
    name: "Shyam"
}
```

# ⚠️ 8. Common Mistake

Don't confuse:

```text
filter() → Array of matches
find()   → One matching item
```

Example:

```text
filter()
   ↓
[
   Customer A,
   Customer B
]
```

But:

```text
find()
   ↓
Customer A
```

### 🧠 Another Important Point

If no item matches, `find()` returns:

```js
undefined
```

So:

```text
Match found    → Customer Object
No match       → undefined
```
