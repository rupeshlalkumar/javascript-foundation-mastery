# 🟦 DAY 23 — `filter()`

### Business Logic Foundation | Selecting Data

---

## 🧠 1. Core Concept

> **`filter()` checks every item against a condition and returns a new array containing only the items that match.**

```text
ARRAY
  ↓
filter()
  ↓
Check Condition
  ↓
Keep Matching Items
  ↓
NEW ARRAY
```

### 📖 Definition

**`filter()`** is an array method used when you want to **select specific items** from an array based on a condition.

---

# 🔵 2. `map()` vs `filter()`

You learned `map()` yesterday.

```text
map()    → Transform items
filter() → Select items
```

### 🧠 Memory Formula

```text
map()
  = Transform
  = Every Item
  = New Array
```

```text
filter()
  = Check Condition
  = Keep Matching Items
  = New Array
```

---

# 💻 3. Basic Syntax

```js
const newArray = array.filter(item => {
    return condition;
});
```

The important part is:

```js
return condition;
```

The condition produces:

```text
true  → KEEP item
false → REMOVE from result
```

---

# 📊 4. Basic Example

Suppose you have:

```js
const numbers = [10, 15, 20, 25, 30];
```

You want only numbers greater than `20`.

```js
const result = numbers.filter(number => {
    return number > 20;
});
```

### Logic

```text
10 > 20 → false → ❌
15 > 20 → false → ❌
20 > 20 → false → ❌
25 > 20 → true  → ✅
30 > 20 → true  → ✅
```

### Result

```js
[25, 30]
```

---

# 🔄 5. Complete `filter()` Flow

```text
             ARRAY
               ↓
            filter()
               ↓
        Check Each Item
               ↓
        ┌──────┴──────┐
        ↓             ↓
      TRUE          FALSE
        ↓             ↓
      KEEP          REMOVE
        │
        ▼
    NEW ARRAY
```

### 🔑 Golden Rule

> **`filter()` keeps the items for which the condition returns `true`.**

---

# 🎯 6. Practice — Filter Active Customers

Suppose your CRM has customers:

```js
const customers = [
    { name: "Rahul", active: true },
    { name: "Krishna", active: false },
    { name: "Binod", active: true },
    { name: "Ram", active: false }
];
```

### 🎯 Your Goal

Create a new array containing **only active customers**.

Think:

```text
Customer Records
       ↓
    filter()
       ↓
Check active
       ↓
active === true
       ↓
Keep Customer
       ↓
Active Customers
```

### 🧠 Think Before Coding

For each customer, ask:

```text
Is active true?
      ↓
   YES → Keep
      ↓
    NO → Remove
```

# ⚠️ 9. Common Mistake

Don't confuse `filter()` with `map()`.

### `map()`

```text
"I want to CHANGE/TRANSFORM every item."
```

### `filter()`

```text
"I want to SELECT certain items."
```

Example:

```text
["Rahul", "Krishna", "Binod"]
          ↓
        filter()
          ↓
Keep names matching condition
```

The original array is not replaced by `filter()`. A **new array** is returned.
