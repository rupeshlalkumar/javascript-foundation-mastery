# 🟦 DAY 25 — `reduce()`

## 🧠 Visual Concept

```text
┌──────────────────────┐
│        ARRAY         │
│  [100, 200, 300]     │
└──────────┬───────────┘
           ↓
┌──────────────────────┐
│       reduce()       │
│  Combine Values      │
└──────────┬───────────┘
           ↓
┌──────────────────────┐
│    SINGLE RESULT     │
│        600           │
└──────────────────────┘
```

> 🟨 **Core Idea:** `reduce()` takes multiple array values and **combines them into one final result**.

---

## 📖 Definition

**`reduce()`** is an array method used to process multiple values and produce **one final result**.

```text
Multiple Values
      ↓
   reduce()
      ↓
 One Final Result
```

---

## 🔍 How `reduce()` Thinks

```text
100
 ↓
200  →  100 + 200 = 300
 ↓
300  →  300 + 300 = 600
 ↓
FINAL RESULT = 600
```

### 🧠 Memory Trick

> **reduce() = MANY → ONE**

---

# 💻 Basic Syntax

```js
const result = array.reduce((total, item) => {
    return total + item;
}, 0);
```

### Breakdown

```text
array
  ↓
reduce()
  ↓
total + item
  ↓
updated total
  ↓
final result
```

* `total` → accumulated result
* `item` → current array value
* `0` → initial value

---

# 💼 Business Example — Sales Revenue

Imagine a business has these sales:

```js
const sales = [1000, 2500, 1500, 3000];
```

We want to calculate **total revenue**.

### 🔄 Logic

```text
Sales Array
    ↓
1000
2500
1500
3000
    ↓
reduce()
    ↓
1000 + 2500 + 1500 + 3000
    ↓
₹8,000
```

### 💻 Code

```js
const sales = [1000, 2500, 1500, 3000];

const totalRevenue = sales.reduce((total, sale) => {
    return total + sale;
}, 0);

console.log(totalRevenue);
```

### Output

```text
8000
```

# 🆚 `map()` vs `filter()` vs `find()` vs `reduce()`

| Method     | Main Job  | Result        |
| ---------- | --------- | ------------- |
| `map()`    | Transform | New Array     |
| `filter()` | Select    | New Array     |
| `find()`   | Search    | First Item    |
| `reduce()` | Combine   | Single Result |

### 🧠 Memory Map

```text
map()
  ↓
TRANSFORM

filter()
  ↓
SELECT

find()
  ↓
SEARCH

reduce()
  ↓
CALCULATE / COMBINE
```

# ⚠ Common Mistake

`reduce()` is not primarily used to create another array.

```text
map()     → New Array
filter()  → New Array
find()    → One Matching Item
reduce()  → One Final Result
```
