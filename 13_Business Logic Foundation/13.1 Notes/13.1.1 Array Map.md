# 🟦 DAY 22 — `map()`

### Business Logic Foundation | Array Transformation

---

## 🧠 1. Core Concept

> **`map()` transforms every item in an array and returns a new array.**

```text
        ARRAY
          │
          ▼
       map()
          │
          ▼
  Transform Each Item
          │
          ▼
      NEW ARRAY
```

### 📖 Definition

**`map()`** is an array method used when you want to **change or transform each item** of an array.

---

## 💻 2. Basic Syntax

```js
array.map(function(item) {
    return transformedItem;
});
```

### Modern Arrow Function

```js
const newArray = array.map(item => transformedItem);
```

### 🧠 Memory Formula

```text
map()
  =
Transform
  +
Every Item
  +
New Array
```

---

## 📊 3. Example: Customer Names

### Original Array

```js
const customers = [
    "Rupesh",
    "Rahul",
    "Anurag",
    "Krishna"
];
```

### Transform Every Name

```js
const customerNames = customers.map(customer => {
    return customer.toUpperCase();
});
```

### Result

```text
Original Array
      ↓
["Rupesh", "Rahul", "Anurag", "Krishna"]
      ↓
     map()
      ↓
Transform Each Name
      ↓
["RUPESH", "RAHUL", "ANURAG", "KRISHNA"]
```

# 💼 5. CRM Example

Imagine a CRM contains customer records:

```js
const customers = [
    { name: "Rupesh", city: "Katihar" },
    { name: "Rahul", city: "Patna" },
    { name: "Anurag", city: "Delhi" }
];
```

You want **only the customer names**.

```js
const customerNames = customers.map(customer => {
    return customer.name;
});
```

### Result

```js
[
    "Rupesh",
    "Rahul",
    "Anurag"
]
```

### Business Flow

```text
CRM Customer Records
        ↓
      map()
        ↓
Extract Customer Name
        ↓
Customer Names List
```
